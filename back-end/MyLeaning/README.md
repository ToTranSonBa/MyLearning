## ?? Key Concepts Explained

### Unit of Work
A pattern that coordinates multiple repositories and transactions. Like a manager that oversees all data changes.

**Files:** [UNITOFWORK_GUIDE.md](UNITOFWORK_GUIDE.md), [STEPBY_STEP_GUIDE.md](STEPBY_STEP_GUIDE.md)

### JWT Authentication
Secure token-based authentication using JSON Web Tokens.

**Files:** [JWT_AUTHENTICATION_SETUP.md](JWT_AUTHENTICATION_SETUP.md), [AUTHENTICATION_FLOW.md](AUTHENTICATION_FLOW.md)

### MediatR Pattern
CQRS pattern implementation for clean command/query handling.

**Files:** [STEPBY_STEP_GUIDE.md](STEPBY_STEP_GUIDE.md#step-2-t?o-handler-v?i-unitofwork)
